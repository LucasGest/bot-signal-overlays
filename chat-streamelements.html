Chat StreamElements

Le chat de l'event dans ton StreamElements

1 Créer l'overlay

  1. Connecte-toi sur streamelements.com avec ton compte Twitch.
  2. Streaming tools → Overlays, puis New overlay, en 1920 × 1080.
  3. Renomme-le Community Event (en haut, à la place de « Unnamed overlay »).
  4. Clique le + bleu, puis Static / Custom → Custom widget.

2 Coller le code

Clique le widget, puis Settings → Open editor. Pour chaque onglet : clique « Copier » ici, puis dans l'onglet du même nom, efface tout (Ctrl+A) et colle (Ctrl+V).

Puis clique Done. Les 4 onglets doivent être remplis : un onglet oublié et le chat reste vide.

3 Placer le widget et enregistrer

  1. Dans Position, size and style : Width 470 · Height 558 · Top 466 · Left 1390.
  2. Clique SAVE.
  3. Pour tester : PREVIEW, puis écris quelques messages dans ton chat Twitch.

4 Le mettre dans OBS

  1. Dans My Overlays, clique ··· sur « Community Event », puis Copy URL. Cette adresse est personnelle : ne la montre pas en stream.
  2. Ouvre l'installateur OBS (/overlay lien sur Discord), connecte-toi, colle l'adresse dans Adresse de ton chat StreamElements, puis Installer dans OBS.

Le chat se place tout seul dans la scène Pause, sous ta webcam.
